Conversor de Documentos a Markdown • SimpleApps Suite

🎯 ¿Qué es el Conversor a Markdown?

Es una utilidad de ingeniería documental que transforma archivos ofimáticos complejos (PDF, Word, Excel, OpenDocument) o texto enriquecido copiado al portapapeles en código Markdown estándar (CommonMark / GFM), limpio, semántico y listo para Obsidian, GitHub, Notion o generadores estáticos.

🔄 Dos Canales de Conversión

1. Adjuntar Archivo

Arrastra o sube tus archivos .docx, .doc, .pdf, .odt, .xlsx, .xls o .ods. El sistema detecta automáticamente el tipo MIME y activa el motor correspondiente.

2. Pegar Contenido / Texto

Copia texto enriquecido desde Word, Google Docs, páginas web o tablas de Excel y pégalo directamente con Ctrl+V. El conversor extrae tanto el formato HTML interno como el texto plano.

📄 Compatibilidad de Formatos y Motores

Extensión Tipo de Documento Motor Interno Local
.docx Microsoft Word 2007+ Mammoth.js (Preserva títulos, negritas, cursivas, listas y tablas)
.xlsx / .xls Microsoft Excel SheetJS + Transpilador GFM (Convierte cada hoja en tabla Markdown)
.ods LibreOffice / OpenOffice Calc SheetJS + Transpilador GFM
.pdf Adobe Portable Document Format PDF.js (Extracción de texto estructurado por capas y páginas)
.odt LibreOffice Writer JSZip + Parser XML nativo para extracción de contenido

📊 Conversión Especializada de Hojas de Cálculo

Al subir un archivo Excel (.xlsx, .xls) o OpenDocument (.ods), el conversor realiza una serie de optimizaciones automáticas:

  • Encabezados automáticos: Toma la primera fila de datos como encabezado de columna y genera la fila divisoria de sintaxis GFM (|---|---|).
  • Múltiples hojas: Si el libro tiene varias pestañas, genera un título de nivel 2 (## Hoja 1) seguido de la tabla correspondiente a cada hoja.
  • Limpieza de celdas: Escapa barras verticales (|) dentro de las celdas para evitar que rompan la estructura de la tabla.
  • Preservación de saltos de línea: Si una celda contiene saltos de línea internos, los sustituye por etiquetas <br> seguras.

⚙️ Personalización del Markdown Saliente

Estilo de Títulos:

Elige entre encabezados prefijados # Título (estilo ATX recomendado) o subrayados === / --- (estilo Setext).

Marcador de Viñetas:

Configura si prefieres guiones (-), asteriscos (*) o símbolos más (+) en listas desordenadas.

Eliminar saltos vacíos:

Normaliza el documento compactando saltos de línea triples o cuádruples en un único espacio interlineal limpio.

Saltos de página:

Inserta separadores horizontales (---) en los saltos de página detectados en archivos PDF y Word.

🛡️ Política de Privacidad, Tratamiento de Datos y Cumplimiento Legal (RGPD)

Para garantizar total transparencia y dar cumplimiento estricto al Reglamento General de Protección de Datos (RGPD / GDPR - Reglamento UE 2016/679) y normativas internacionales de privacidad, informamos sobre el tratamiento de documentos según el entorno de ejecución:

💻 Ejecución Local (On-Premise / Localhost)

Cero Envío de Datos (100% Offline): Si ejecutas esta herramienta en tu entorno local (localhost, servidor interno o PC personal), NO se envía ningún documento, archivo ni telemetría a servidores externos. Todo el proceso de extracción de PDF, Word (.docx) y planillas (.xlsx, .ods) se ejecuta en la memoria RAM de tu navegador. Ningún byte o texto abandona tu dispositivo.

🌐 Versión Web en Línea (Online / Cloud)

Uso Exclusivo para la Tarea Solicitada (Art. 5.1.b RGPD): En la versión web alojada en línea, los documentos cargados se transmiten bajo conexión segura y cifrada (HTTPS/TLS). Dichos datos se procesan ÚNICAMENTE para ejecutar y finalizar la tarea técnica solicitada.

Sin Persistencia ni Cesión: El contenido se procesa de manera efímera en memoria volátil. NO se almacenan de forma permanente, NO se realizan copias de seguridad de sus contenidos, NO se comparten con terceros ni se utilizan para minería de datos ni entrenamiento de modelos de IA, eliminándose automáticamente al completar la conversión o finalizar la sesión.
