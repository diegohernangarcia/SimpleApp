🎯 ¿Qué es el Generador SQL desde Excel?

Es una herramienta de alta velocidad diseñada para desarrolladores, analistas y administradores de bases de datos que necesitan migrar, importar o sincronizar planillas de cálculo (Excel, CSV, ODS) hacia bases de datos relacionales sin requerir conectores pesados ni subir datos a servidores de terceros.

🔄 Flujo de Trabajo en 4 Pasos

  • Paso 1 (Carga): Arrastra tu archivo (.xlsx, .xls, .ods, .csv, .tsv) o pega texto tabulado desde el portapapeles.
  • Paso 2 (Mapeo y Tipado): Activa/desactiva columnas, renombra identificadores a snake_case, verifica los tipos de datos inferidos y define la Clave Primaria (PK).
  • Paso 3 (Configuración SQL): Selecciona el motor de destino (MySQL, Postgres, SQLite, etc.), el tipo de sentencia (INSERT, UPSERT, REPLACE, UPDATE) y el tamaño del lote.
  • Paso 4 (Generación y Exportación): Visualiza el código SQL resultante, cópialo con un clic o descárgalo como archivo .sql listo para ejecutar en tu cliente de base de datos favorito (DBeaver, phpMyAdmin, DataGrip, HeidiSQL).

📂 Métodos de Entrada de Datos

El módulo ofrece tres canales ultrarrápidos para importar registros:

  • Arrastrar y Soltar (Drag & Drop): Soporta archivos de Excel moderno (.xlsx), binario antiguo (.xls), LibreOffice Calc (.ods), y valores separados por coma o tabulación (.csv, .tsv, .txt).
  • Pegado Directo (Clipboard): Presiona el botón Pegar Datos (Clipboard) o copia una tabla en Excel / Google Sheets y pégala aquí. El sistema detecta automáticamente los delimitadores tabulados.
  • Presets de 1 Clic: Carga al instante conjuntos de demostración prediseñados (Productos E-commerce, Usuarios CRM, Libro Diario Contable).

📑 Soporte para Libros Multi-Hoja

Si tu archivo Excel contiene más de una pestaña, aparecerá un menú desplegable permitiéndote elegir exactamente qué hoja procesar.

🏷️ Configuración de Esquema por Columna

  • Casilla Inc. (Incluir): Desmarca cualquier columna que no desees exportar al script SQL.
  • Nombre en SQL: Personaliza el identificador de cada campo. Usa el botón 🪄 Sanitizar a snake_case para quitar acentos, espacios y símbolos de una sola vez.
  • Tipo de Dato: El motor infiere automáticamente entre INTEGER, DECIMAL(12,2), VARCHAR(255), TEXT, BOOLEAN, DATE y DATETIME. Puedes forzar cualquier tipo manualmente.
  • Clave Primaria (🔑 PK): Haz clic en la insignia para designar las columnas que identifican unívocamente a cada registro. Es obligatorio para operaciones UPDATE y UPSERT.

🗄️ Dialectos Soportados

  • MySQL / MariaDB: Delimitadores con comillas invertidas (`tabla`), escape seguro \', INSERT IGNORE y ON DUPLICATE KEY UPDATE.
  • PostgreSQL: Delimitadores con comillas dobles ("tabla"), booleanos TRUE/FALSE y cláusula ON CONFLICT (...) DO UPDATE.
  • SQLite: Ideal para bases de datos locales o embebidas; soporta REPLACE INTO e INSERT OR IGNORE.
  • MS SQL Server & Oracle: Sintaxis T-SQL ([tabla]) y PL/SQL con transacciones compatibles.

⚡ Tipos de Operación SQL

  • INSERT INTO: Inserción masiva estándar de nuevas filas.
  • INSERT IGNORE: Omite duplicados sin lanzar errores ni abortar el script.
  • UPSERT: Inserta si es nuevo, o actualiza los datos si la Clave Primaria ya existe.
  • REPLACE INTO: Elimina el registro antiguo e inserta el nuevo (MySQL/SQLite).
  • UPDATE por lotes: Sentencias individuales con cláusula WHERE pk = valPK.

📜 Pestañas de Visualización

  • Script SQL Generado: El código SQL completo listo para ejecución, formateado y segmentado en lotes.
  • Vista Previa de Datos: Tabla interactiva mostrando los primeros 50 registros de la planilla con sus nombres SQL y tipos.
  • Definición DDL (CREATE TABLE): Script complementario CREATE TABLE IF NOT EXISTS generado automáticamente con las columnas y claves primarias definidas.

💾 Opciones de Exportación

Presiona Copiar al Portapapeles para pegar directamente en DBeaver, phpMyAdmin, HeidiSQL o DataGrip, o pulsa Descargar Archivo .sql para guardarlo en tu disco local.

🚀 ¿Por qué segmentar en lotes de 500 o 1.000 filas?

Ejecutar sentencias INSERT individuales por cada registro genera miles de viajes de red redundantes. Al agrupar las filas en bloques de 500 filas en una sola sentencia VALUES (...), (...), la velocidad de importación aumenta en más del 95% respetando los límites de memoria del paquete (como max_allowed_packet en MySQL).

🛡️ Escape Seguro y Transacciones

Todas las cadenas de texto son escapadas contra inyecciones SQL (comillas, barras invertidas, saltos de línea). La casilla Envolver en Transacción agrega START TRANSACTION / COMMIT para garantizar atomicidad y prevenir registros a medio cargar si se interrumpe la conexión.
