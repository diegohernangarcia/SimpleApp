🎯 Modelo de Seguridad de Archivos UNIX/Linux

En los sistemas tipo POSIX (Linux, macOS, BSD), cada archivo y directorio tiene asignado un propietario (Owner/User), un grupo asignado (Group) y el resto de usuarios del sistema (Others). Cada uno de estos tres dominios tiene 3 derechos fundamentales:

Lectura (r = 4)

Archivos: Ver el contenido del archivo.
Carpetas: Listar los archivos contenidos (ls).

Escritura (w = 2)

Archivos: Modificar o truncar.
Carpetas: Crear, renombrar o borrar archivos dentro.

Ejecución (x = 1)

Archivos: Ejecutar binario o script.
Carpetas: Entrar con cd o acceder a inodos.

🔒 Bits Especiales (Cuarto Dígito Octal)

Se anteponen al número de 3 dígitos (ej: 4755, 2775, 1777):

SUID (Set User ID = 4)

El binario se ejecuta temporalmente con los privilegios del propietario del archivo (ej: /usr/bin/passwd que necesita acceso root).

SGID (Set Group ID = 2)

En carpetas, todo nuevo archivo creado heredará automáticamente el grupo de la carpeta en vez del grupo primario del creador.

Sticky Bit (Restricted Deletion = 1)

En carpetas compartidas como /tmp (1777), solo el dueño de un archivo o root puede borrarlo o renombrarlo.

🛡️ Máscara de Creación (Umask)

La umask define qué permisos se restan o deniegan a los archivos y directorios recién creados:

  • Permiso base carpetas: 0777 (rwxrwxrwx)
  • Permiso base archivos: 0666 (rw-rw-rw-)
  • Umask común 0022: Archivos resultan en 0644 (rw-r--r--) y carpetas en 0755 (rwxr-xr-x).
  • Umask estricta 0027: Otros usuarios no tienen acceso alguno (archivos 0640, carpetas 0750).

💻 Generador de Comandos Chmod

La aplicación genera automáticamente tanto la sintaxis octal (chmod 755 archivo.sh) como la sintaxis simbólica (chmod u=rwx,g=rx,o=rx archivo.sh) con opciones para ejecución recursiva (-R).
