Calculadora de Permisos Linux & Unix

Conversión bidireccional instantánea entre notación octal (3 y 4 dígitos), formato simbólico (rwxr-xr-x) y matriz de bits. Incluye permisos especiales (SUID, SGID, Sticky), calculadora de umask y generador de comandos listos para terminal.

Permisos Especiales (Special Bits) SUID (4000) • SGID (2000) • Sticky (1000)
4000 / 's'

Se ejecuta con los privilegios del propietario del archivo (ej. root).

2000 / 's'

Hereda grupo del directorio o corre con permisos del grupo creador.

1000 / 't'

En directorios como /tmp, solo el dueño puede borrar sus propios archivos.

Seguridad Estándar Unix / Web

Cumple el principio de privilegios mínimos para servidores web y documentación pública.

Propietario (User): Puede leer, modificar y ejecutar este archivo.
Grupo (Group): Puede leer y ejecutar, pero NO modificar.
Otros (Others): Cualquier usuario del sistema puede únicamente leer y ejecutar.
Regla Nemotécnica Octal:
Lectura = 4 • Escritura = 2 • Ejecutar = 1.
Suma los bits para obtener cada dígito (ej: 4+2+1 = 7, 4+0+1 = 5).

Generador Inteligente de Comandos Terminal

Comandos listos para copiar y pegar directamente en bash, zsh o scripts SSH.
Ruta / Archivo:
Usuario:Grupo:
1. Comando Chmod Octal
chmod 755 /var/www/html
2. Comando Chmod Simbólico Absoluto
chmod u=rwx,g=rx,o=rx /var/www/html
3. Buenas Prácticas SysAdmin / Web (Find & Chmod)
find /var/www/html -type d -exec chmod 755 {} +
find /var/www/html -type f -exec chmod 644 {} +
4. Comando Chown (Dueño y Grupo)
chown www-data:www-data /var/www/html

Calculadora Interactiva de Umask

Calcula los permisos por omisión asignados al crear archivos (base 666) y directorios (base 777).
Nuevos Archivos Creados (Base 666)
644
-rw-r--r--

Operación lógica: 666 & ~umask. Los bits del umask se restan de los permisos máximos.

Nuevos Directorios Creados (Base 777)
755
drwxr-xr-x

Operación lógica: 777 & ~umask. Garantiza acceso de navegación (x) para carpetas.
