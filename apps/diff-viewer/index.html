Manual Operativo & Guía de Uso

Comparador de Texto y Código • SimpleApps Suite

🎯 ¿Qué es Diff Viewer?

Es una estación de trabajo de inspección visual de diferencias entre dos versiones de un texto o código fuente (Original A vs Modificado B). Permite pegar texto plano, subir archivos fuente (JSON, SQL, Python, JavaScript, CSS, HTML, Markdown, config) o cargar ejemplos predefinidos en un clic.

⚡ Flujo de Comparación Rápida

1. Ingresar Datos

Pega texto en los paneles A y B, o arrastra archivos locales a cada editor.

2. Ejecutar Comparación

Haz clic en "Comparar Textos" o pulsa Ctrl+Enter para computar las diferencias.

3. Navegar & Exportar

Salta entre diferencias con los botones de navegación o copia el informe consolidado.

👁️ Vista Dividida (Side-by-Side)

Muestra el texto Original en la columna izquierda y el texto Modificado en la columna derecha con scroll sincronizado. Ideal para revisar cambios estructurales, adiciones y sustituciones de código frente a frente.

📑 Vista Unificada (Inline)

Presenta un único flujo secuencial lineal con prefijos + (verde) y - (rojo), idéntico a las salidas de comandos de Git (git diff) o plataformas como GitHub y GitLab.

🎨 Código de Colores Semántico

  • Rojo (-): Líneas o caracteres eliminados en el texto original.
  • Verde (+): Líneas o caracteres añadidos en el texto modificado.
  • Ámbar (~): Líneas modificadas (con micro-resaltado de caracteres internos cambiados).

🔍 Algoritmo Myers Diff

Implementa la variante estándar de O(ND) del algoritmo de Myers, encontrando la secuencia de edición más corta (Shortest Edit Script) para garantizar comparaciones precisas y deterministas en documentos grandes.

✨ Resaltado Intra-Línea (Char-by-Char)

Cuando una línea solo sufre modificaciones menores (como una palabra cambiada, un typo o un valor de variable), el visor no solo marca la línea completa sino que resalta con mayor intensidad los caracteres específicos añadidos o eliminados.

⌨️ Atajos de Teclado

Atajo Acción
Ctrl + Enter / Cmd + Enter Ejecutar comparación de inmediato.
Alt + N / Alt + P Saltar a la siguiente / anterior diferencia.
Esc Cerrar ventanas modales o diálogos emergentes.

⚙️ Filtros Inteligentes

En la barra de herramientas puedes activar o desactivar:

  • Ignorar espacios en blanco: Omite diferencias de indentación o espacios adicionales al final de línea.
  • Ignorar mayúsculas/minúsculas: Compara texto en modo case-insensitive.

🛡️ Política de Privacidad, Tratamiento de Datos y Cumplimiento Legal (RGPD)

Para garantizar total transparencia y dar cumplimiento estricto al Reglamento General de Protección de Datos (RGPD / GDPR - Reglamento UE 2016/679) y normativas internacionales de privacidad, informamos sobre el tratamiento de datos y textos según el entorno de ejecución:

💻 Ejecución Local (On-Premise / Localhost)

Cero Envío de Datos (100% Offline): Si ejecutas esta herramienta en tu entorno local (localhost, servidor interno o PC personal), NO se envía ningún dato, archivo ni telemetría a servidores externos. Los cálculos del algoritmo Myers Diff y resaltado intra-línea se ejecutan de forma inmediata en la memoria RAM del navegador. Ningún byte o carácter sale de tu equipo.

🌐 Versión Web en Línea (Online / Cloud)

Uso Exclusivo para la Tarea Solicitada (Art. 5.1.b RGPD): En la versión web alojada en línea, los textos o archivos comparados se transmiten bajo conexión segura y cifrada (HTTPS/TLS). Dichos datos se procesan ÚNICAMENTE para ejecutar y finalizar la tarea técnica solicitada.

Sin Persistencia ni Cesión: El código y texto se analizan de manera estrictamente efímera en memoria volátil. NO se almacenan de forma permanente, NO se realizan copias de seguridad de sus contenidos, NO se comparten con terceros ni se utilizan para minería de datos ni entrenamiento de modelos de IA, eliminándose automáticamente al cerrar la pestaña o concluir la sesión.
