🎯 ¿Qué es el Generador ASCII Tree?

                        
Es una herramienta de diagramación técnica bi-direccional diseñada para desarrolladores, sysadmins y arquitectos de software:

                        

                            

                                Modo 1: Rutas a Árbol Gráfico
                                
Ingresa una lista de rutas de archivos (o arrastra una carpeta local) y genera al instante un árbol jerárquico impecable para documentar proyectos en archivos README.md, Wikis o especificaciones.

                            

                            

                                Modo 2: Árbol a Script CLI (Inverso)
                                
Pega un diagrama de árbol existente copiado de un tutorial o documentación y genera automáticamente scripts ejecutables para Bash (Linux/macOS), PowerShell (Windows) o CMD que crean toda la estructura con mkdir y touch.

                            

                        

                    

                


                
                

                    

                        
🌲 4 Estilos Gráficos Disponibles

                        
Selecciona el formato que mejor se adapte a tu medio de publicación:

                        

                            
                                

                                    Estilo
                                    Caracteres
                                    Uso Recomendado
                                

                            
                            
                                

                                    Unicode Moderno
                                    ├── └── │
                                    Estándar visual de la herramienta tree en Linux, perfecto para GitHub y Notion.
                                

                                

                                    ASCII Clásico
                                    |-- \-- |
                                    Máxima compatibilidad con terminales legadas o fuentes sin soporte UTF-8.
                                

                                

                                    Markdown List
                                    - item con indentación
                                    Listas anidadas nativas de Markdown listas para renderizar como HTML.
                                

                                

                                    Bullet / Minimal
                                    • item
                                    Documentación ejecutiva, presentaciones y diagramas simplificados.
                                

                            
                        

                    

                


                
                

                    

                        
⚡ De Diagrama a Código Ejecutable

                        
¿Encontraste una plantilla de arquitectura en un tutorial o documentación oficial? Con el Modo Inverso:

                        
    
                            
  • El parser inteligente detecta ramas de cualquier estilo (Unicode, barras, espacios o guiones).
    • 
                            
  • Identifica qué elementos son carpetas (terminan en / o tienen hijos) y cuáles son archivos (con extensión).
    • 
                            
  • Genera comandos agrupados mkdir -p y touch (o New-Item en PowerShell).
    • 
                            
  • Permite copiar el script al portapapeles o descargarlo como archivo .sh o .ps1 listo para ejecutar con un doble clic.
    • 
                        

                    

                


                
                

                    

                        
📐 Formato de Entrada de Rutas

                        
En el editor del Modo 1 puedes escribir o pegar rutas con cualquier estilo:

                        
    
                            
  • Rutas relativas con barra: src/components/Header.jsx
    • 
                            
  • Rutas con contrabarra de Windows: app\models\user.py
    • 
                            
  • Rutas anidadas con sangría de espacios o tabulaciones.
    • 
                            
  • Carpetas vacías indicadas agregando una barra final: logs/ o temp/cache/.
    •

Puedes personalizar: inclusión de carpeta raíz (Root Name), inclusión de iconos/emojis según extensión de archivo, ordenamiento alfabético y orden primero-directorios.

                    

                


                
                

                    

                        
🛡️ Política de Privacidad, Tratamiento de Datos y Cumplimiento Legal (RGPD)

                        
Para garantizar total transparencia y dar cumplimiento estricto al Reglamento General de Protección de Datos (RGPD / GDPR - Reglamento UE 2016/679) y normativas de privacidad, informamos sobre el tratamiento según el entorno de ejecución:

                        

                            

                                💻 Ejecución Local (On-Premise / Localhost)
                                
Cero Envío de Datos (100% Offline): Si ejecutas esta herramienta en tu entorno local (localhost o máquina de trabajo), NO se envía ningún dato, archivo, árbol ni telemetría a servidores externos. Al arrastrar una carpeta, el navegador únicamente lee los nombres de las rutas en memoria local a través de la API FileSystem de HTML5, sin leer ni transmitir el contenido interno de tus ficheros. Ningún dato sale de tu dispositivo.

                            

                            

                                🌐 Versión Web en Línea (Online / Cloud)
                                
Uso Exclusivo para la Tarea Solicitada (Art. 5.1.b RGPD): En la versión web alojada en línea, las estructuras o árboles enviados se transmiten bajo conexión segura y cifrada (HTTPS/TLS). Dichos datos se procesan ÚNICAMENTE para ejecutar y finalizar la tarea técnica solicitada.

                                
Sin Persistencia ni Cesión: Los árboles generados se procesan de forma efímera en memoria volátil. NO se almacenan de forma permanente, NO se crean copias de seguridad de sus contenidos, NO se comparten con terceros ni se utilizan para minería de datos ni entrenamiento de modelos de IA, eliminándose automáticamente al abandonar la herramienta.
