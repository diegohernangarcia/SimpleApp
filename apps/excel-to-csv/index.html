🎯 ¿Qué hace este módulo?

Lee libros de cálculo de Microsoft Excel (.xlsx, .xls, .xlsm, .xlsb) y OpenDocument Spreadsheet (.ods), detecta automáticamente cada una de sus hojas de cálculo y permite exportarlas individualmente o en conjunto como archivos de texto plano CSV delimitados con máxima precisión de datos.

⚡ Flujo de Extracción Paso a Paso

1. Subir el Libro

Arrastra tu archivo Excel a la dropzone. El lector analiza instantáneamente la estructura interna y metadatos del libro.

2. Elegir Hojas y Parámetros

Selecciona qué hojas deseas exportar. Configura el delimitador (, ; \t |) y si deseas incluir cabecera o BOM UTF-8.

3. Descarga Directa o ZIP

Descarga cada hoja de forma individual o pulsa "Descargar Todas en ZIP" para obtener un archivo comprimido organizado.

📑 Soporte Multi-Hoja Completo

A diferencia de la función estándar "Guardar como CSV" de Microsoft Excel (que únicamente guarda la pestaña activa y descarta las demás), este módulo:

  • Escanea y lista todas las pestañas del libro con su conteo de filas y columnas.
  • Permite marcar/desmarcar individualmente qué hojas quieres procesar con casillas de selección rápida.
  • Permite previsualizar los primeros registros de cada hoja en una tabla interactiva antes de descargar.

📦 Empaquetado Automático en ZIP

Al pulsar Descargar en ZIP, el motor empaqueta todas las hojas seleccionadas dentro de un archivo comprimido .zip manteniendo nombres claros como NombreArchivo_NombreHoja.csv sin necesidad de descargar archivo por archivo manualmente.

🔀 Selección del Delimitador de Columnas

Configura el carácter separador según el software o base de datos que consumirá el archivo:

Delimitador Carácter Uso Recomendado
Coma , Estándar internacional para Python, Pandas, R, PostgreSQL y MySQL.
Punto y coma ; Recomendado para Excel en español, evitando conflictos con decimales.
Tabulación \t Formato TSV ideal para copiar y pegar en procesadores de texto y scripts.
Pipe | Muy utilizado en sistemas bancarios, AS/400 y cargas masivas (ETL).

📝 Reglas de Encomillado (RFC 4180)

Si una celda contiene el separador seleccionado, saltos de línea o comillas dobles, el generador encierra automáticamente el texto entre comillas dobles y escapa cualquier comilla interna ("") cumpliendo estrictamente con la especificación RFC 4180.

📅 Formateo Preciso de Fechas y Números

Excel almacena fechas como números de serie flotantes (ej. 44927). Este conversor las interpreta con su formato de visualización real o en formato estandarizado ISO YYYY-MM-DD según tu necesidad.

🔤 Codificación UTF-8 con BOM

Incluye la opción de anteponer la marca de orden de bytes (BOM UTF-8). Esto soluciona el clásico fallo de Excel en Windows donde caracteres acentuados, eñes o caracteres cirílicos/asiáticos se muestran como símbolos extraños (mojibake).
